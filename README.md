## 📖 Sobre o Projeto

O jogo contém uma recriação do clássico jogo **Tetris**, contendo diferentes modos e dificuldades para customizar a experiência e se adaptar à jogadores de diferentes níveis de experiência. O jogo contém todas as funcionalidades do jogo original, incluindo rotação de peças, fast-drop e a possibilidae de "segurar" uma peça no inventário.

O projeto contém 3 modos diferentes de jogo:
- Clássico: Segue as mesmas regras dos jogos originais.
- Sobrevivência: Com o decorrer do jogo, novas camadas de blocos surgem para forçar o jogador a argir com urgência e assertividade em relação aos blocos posicionados. Esse modo incluí 4 níveis de dificuldade que mudam a velocidade de geração desss novas camadas. 
- Torre: Nesse modo a lógica do jogo se altera, o objetivo é destruir a torre composta de camadas de blocos cinzas e o desafio é destruí-la da forma mais rápida possível. Esse modo inclí 4 alturas diferentes de torres para selecionar (o layout delas é aleatório).
